**[adata/common/utils/sunrequests.py](file:///c:/Users/wangp/Desktop/CompassJudger-2/字节/adata-2/adata/common/utils/sunrequests.py)** - 请求工具类，包含：

- `SunProxy` - 代理配置类（保持原有功能）

- `set_rate_limit()` - 设置频率限制的便捷函数

### 3. 使用方式

```python
import adata

# 设置默认频率限制：每分钟30次（默认值）
adata.rate_limit()

# 设置特定域名的频率限制：每分钟60次
adata.rate_limit('quote.eastmoney.com', limit=60)

# 设置特定域名的频率限制：每10秒5次
adata.rate_limit('api.example.com', limit=5, window=10)
```

### 4. 设计特点

1. **优雅的单例模式**：`RateLimiter` 使用单例模式确保全局只有一个频率限制器实例
2. **基于域名的限制**：可以为不同域名设置不同的频率限制
3. **线程安全**：使用锁机制确保多线程环境下的安全
4. **自动等待**：当达到频率限制时，自动计算并等待合适的时间
5. **向后兼容**：保持原有的 `SunProxy` 代理功能不变

由于代码库中的其他模块（如 stock, fund, bond 等）的 `__init__.py` 文件只包含导入语句，实际的请求代码可能在其他地方。当实际请求代码使用 `sun_requests.get()`、`sun_requests.post()` 等方法时，频率限制会自动生效。
